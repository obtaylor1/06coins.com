Add Hover Zoom Effect to Coin Images

You are a senior front-end developer updating the /shop-coins page.

Your task is to apply a smooth hover zoom animation to each coin image in the Founders' Legacy Set and the individual Jewel coins.

Follow these instructions exactly:

1. Identify all coin images

Locate the HTML that renders each coin in the Jewel Set section and in the Individual Jewel Coins carousel.
These may be inside a container such as:

.jewel-coin

.coin-image

.jewel-card img

or whatever class the project uses.

2. Add a wrapper class around each coin image

If not already present, wrap each <img> in a container with this class:

<div class="coin-hover-wrapper">
    <img src="..." alt="...">
</div>


If wrappers already exist, only apply the class to them.

3. Add this CSS to the main stylesheet

Add the following styling (keep in black + gold aesthetic):

/* Wrapper prevents layout shifting */
.coin-hover-wrapper {
  display: inline-block;
  overflow: visible;
  transition: transform 0.3s ease-in-out;
  cursor: pointer;
}

/* Image behavior */
.coin-hover-wrapper img {
  transition: transform 0.35s ease-in-out, filter 0.35s ease-in-out;
  transform-origin: center center;
}

/* Hover zoom effect */
.coin-hover-wrapper:hover img {
  transform: scale(1.35); /* increase to 1.5 if you want more zoom */
  filter: drop-shadow(0 8px 12px rgba(212, 175, 55, 0.35)); /* subtle gold glow */
}

4. Ensure responsive behavior

Make sure max-width is preserved so images don’t break layout:

.coin-hover-wrapper img {
  max-width: 100%;
  height: auto;
}


On mobile, keep zoom smaller (optional):

@media (max-width: 768px) {
  .coin-hover-wrapper:hover img {
    transform: scale(1.15);
  }
}

5. Apply class to ALL coin images

Apply .coin-hover-wrapper to:

All seven Jewel coins in the Founders' Legacy Set

All individual coins in the carousel

Any other coin image sections if present.

6. Do NOT affect the layout

The effect should:

Zoom the image in place

Not push other content around

Not cause layout shift

Have smooth animation in and out

7. After implementing

Verify:

Hovering over any coin enlarges it smoothly

Hover out returns to normal size

Images stay centered

Shadow glow is subtle and premium

No console errors

Make all changes now.
